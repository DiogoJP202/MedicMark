# Segurança do MedicMark

## Versões suportadas

A versão mais recente da linha `0.1.x` recebe correções de segurança. Versões anteriores devem ser
atualizadas antes de abrir um novo relato.

## Relatar uma vulnerabilidade

Use o
[relato privado de vulnerabilidade](https://github.com/DiogoJP202/MedicMark/security/advisories/new).
Não publique credenciais, tokens, dados operacionais, endereços internos ou detalhes exploráveis
em uma issue pública.

Inclua somente o necessário para reproduzir:

- versão e plataforma;
- componente afetado;
- impacto observado;
- passos de reprodução sem dados reais;
- mitigação temporária, se houver.

Problemas comuns sem impacto de segurança podem ser enviados pelos
[Issues](https://github.com/DiogoJP202/MedicMark/issues).

## Integridade dos downloads

Baixe os aplicativos apenas pela
[página oficial](https://diogojp202.github.io/MedicMark/) ou pelos
[GitHub Releases](https://github.com/DiogoJP202/MedicMark/releases). Cada versão publica hashes
SHA-256 e usa release imutável. O APK Android também deve estar assinado pela identidade MedicMark.
