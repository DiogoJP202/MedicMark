# MedicMark 0.1.3

Primeira distribuição pública gratuita para Android e Windows x64.

## Downloads

- `MedicMark-Android.apk`: Android 7.0 ou superior, assinado pela identidade MedicMark.
- `MedicMark-Windows-x64.zip`: Windows 10 versão 1809 ou superior, portátil e autocontido.
- `SHA256SUMS.txt`: hashes para conferir a integridade dos arquivos.
- `MedicMark-Android-certificate.pem`: certificado público da assinatura Android.

## Segurança

- servidor oficial predefinido e oculto na interface dos builds Release;
- somente HTTPS para servidores alternativos em produção;
- backup do aplicativo desativado no Android;
- release e tag imutáveis após a publicação.

O Android pode solicitar autorização para instalar aplicativos desta fonte. O Windows pode exibir
um aviso do SmartScreen porque esta distribuição gratuita ainda não possui certificado comercial.
Não desative o antivírus; confira sempre o SHA-256 e a origem do download.
