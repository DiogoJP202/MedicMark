MEDICMARK — CHECKLIST DE PLANTÃO

REQUISITOS
- Windows 10 versão 1809 ou superior, arquitetura x64.
- Acesso ao servidor oficial pela internet.

COMO ABRIR
1. Extraia todo o conteúdo deste ZIP para uma pasta.
2. Abra ChecklistPlantao.Client.exe.
3. Mantenha o aplicativo aberto ou minimizado para receber alertas no Windows.

SEGURANÇA
- Baixe somente de https://diogojp202.github.io/MedicMark/
- Confira o SHA-256 publicado no mesmo GitHub Release.
- Esta distribuição gratuita ainda não possui certificado comercial. O SmartScreen pode exibir
  um aviso de aplicativo não reconhecido. Não desative o Microsoft Defender.
