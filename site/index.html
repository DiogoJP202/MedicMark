Integridade e transparência

Como conferir o arquivo

Compare o SHA-256

Baixe os hashes publicados junto da versão:

Abrir SHA256SUMS.txt

Get-FileHash .\MedicMark-Windows-x64.zip -Algorithm SHA256

Verifique o release

Com o GitHub CLI instalado, confirme que o release e o arquivo são imutáveis:

gh release verify v0.1.3 --repo DiogoJP202/MedicMark
gh release verify-asset v0.1.3 .\MedicMark-Android.apk --repo DiogoJP202/MedicMark

Avisos do sistema

O que pode aparecer na primeira instalação

Android

Como o app é distribuído fora da Play Store, o Android solicitará autorização para instalar aplicativos desta fonte. Isso não deve exigir desativar o Play Protect.

Windows

Esta distribuição gratuita ainda não possui certificado comercial. O SmartScreen pode exibir “aplicativo não reconhecido”. Confira a origem e o SHA-256 antes de abrir; não desative o antivírus.
